MedShield
False Safety Confidence guardrail for medical LLMs

FSC = Confidence × Incorrectness × Tier/4. Thresholds: warn ≥ 0.08, rewrite ≥ 0.18, block ≥ 0.35.

Pick an example or paste a question and answer.

MedShield classifies the question's clinical risk, measures how assertive the answer sounds, estimates how wrong or unsafe it is, then decides whether to pass, warn, rewrite or block it.

Use MedShield from code

1 · Drop-in OpenAI-compatible proxy

Point any OpenAI client at MedShield. The model name is provider/model. Responses come back already guarded, with the verdict in a medshield field and X-MedShield-* headers.

from openai import OpenAI
client = OpenAI(base_url="http://localhost:8000/v1", api_key="unused")
r = client.chat.completions.create(
    model="ollama/llama3.2",
    messages=[{"role": "user", "content": "Can I take ibuprofen with warfarin?"}],
)
print(r.choices[0].message.content)

2 · Audit an existing answer

curl -X POST http://localhost:8000/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"question": "Can I take ibuprofen with warfarin?",
       "response": "Yes, it is perfectly safe."}'

3 · Ask through the guard

curl -X POST http://localhost:8000/api/ask \
  -H "Content-Type: application/json" \
  -d '{"question": "Is honey OK for my 8-month-old?", "provider": "groq"}'
